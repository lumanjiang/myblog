这个博客最方便的地方是：**写文章不用碰代码，也不用开命令行**。

## 在网页上写

网站部署好之后，访问 `你的网址/admin`，用 GitHub 账号登录，就会进入一个写作后台。

界面很直观：

- 点 "New 文章" 新建一篇
- 填标题、日期、摘要、标签
- 正文区域可以直接用富文本编辑，也可以切换成 Markdown 模式
- 图片直接拖进去就能上传

## 发布

写完点右上角的 **Publish**，后台会自动把文章保存到代码仓库，网站在一两分钟内自动重新构建、上线。整个过程你只需要在浏览器里操作。

## 草稿

如果只想先存着不发布，把 `draft` 勾上（或者在后台用 Save as draft），文章就不会出现在网站上。

## 想改样式的时候

样式集中在 `app/globals.css`，网站标题和简介在 `site.config.js`。这两个文件改一改就能换个风格，不改也完全能用。
